# Site Institucional Dra. Rita de Cássia Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformar a landing page existente em um site institucional premium, responsivo e transparente para Dra. Rita de Cássia.

**Architecture:** Conteúdo factual centralizado em `src/data/siteContent.js`, componentes de apresentação em React e um hook isolado para animações GSAP. CSS global mantém tokens/reset e `App.css` organiza os blocos editoriais e breakpoints.

**Tech Stack:** React 19, Vite 8, CSS moderno, GSAP 3 + ScrollTrigger, `node:test` com SSR/build do Vite.

**Spec:** `docs/superpowers/specs/2026-11-01-dra-rita-design.md`

## Global Constraints

- Usar exatamente: `NOVO OLHAR`, local `Clínica Affetos`, endereço `Rua Batista Renzi, 96 — Suzano, São Paulo.`
- Usar exatamente: `ORAL FACE`, `Rua Teresa Clementina Tomasine de Freitas, 248`, `Parque Maria Helena`, `Suzano — SP`, `08683-280`.
- Usar exatamente as áreas informadas: `Harmonização Orofacial (HOF)`, `Implantodontia` e `Blefaroplastia`, sempre vinculadas ao aviso de validação pré-publicação.
- Não inventar contatos, horários, títulos, certificados, avaliações ou resultados clínicos.
- Manter `CRO-XXXXXXX` e aviso explícito para validação antes da publicação.
- Informar na interface que títulos, habilitações, registro e comunicação de procedimentos dependem de verificação junto aos conselhos profissionais.
- FAQ e metadados não podem criar alegações sobre indicação, segurança, benefícios, recuperação, prognóstico ou resultados.
- Tratar todas as fotografias como imagens ilustrativas da modelo.
- Não realizar submissão nem armazenamento do formulário.
- Usar `details/summary`, foco visível, contraste AA, alvos de 44 px e dimensões explícitas nas imagens; somente o hero tem carregamento prioritário.

## Review Focus

- A modelo nunca pode ser identificada textual ou semanticamente como Dra. Rita.
- Links de mapas devem pesquisar os endereços exatos e abrir com proteção `noopener`.
- Links de mapas devem usar query literal codificada, `target="_blank"` e `rel="noopener noreferrer"`.
- O formulário não pode possuir `action`, simular sucesso ou coletar dados; o botão deve ser `type="button"` e o aviso precisa ser visível.
- GSAP deve limpar listeners/triggers e respeitar movimento reduzido.
- Em 320 px, header, fotografias, cards e formulário não podem gerar overflow horizontal.
